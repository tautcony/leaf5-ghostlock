## 四、CORRECTED / 文档缺口（本次处理）

1. **S02 stages 探针 ≠ mm 泄漏**  
   `test_ks_minimal` / `test_kernelsnitch_minimal` 只验证 mmap/futex 组件；**真泄漏**在 `exploit/test-programs/test_mm_leak`（及集成 `slide.c`）。旧 README 过称「设备上可靠泄漏」已收紧。

2. **S03 无独立 sk_buff 探针**  
   节点仅有 `check_ion_primitive.sh` + 指向 `exploit/src/heap_spray.c`。shell 对 `/dev/ion` open 失败。spray **4/4** 仍为历史/集成结论，本次未单独 C 复测。

3. **S04 无独立二进制**  
   触发逻辑嵌在 S05 `ghostlock*.c` / exploit `main.c`。复测确认 requeue ret=1。

4. **S05-01 / 04 / 06**  
   以分析+权限探测为主，无「可成功覆盖」的 PoC（符合关闭结论）。

5. **`test_ctx_flags` 曾漏测 0x12**  
   探针已补；复测 0x12 成功。

6. **`test_egl` 静态链接失败**  
   Makefile 对 `test_egl.c` 改用 `-pie -ldl`；结论仍为「无完整用户态驱动时有限」。
